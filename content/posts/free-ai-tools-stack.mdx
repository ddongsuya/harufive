AI 도구는 대부분 무료 플랜이 있습니다. 문제는 무료 플랜이 없다는 것이 아니라, **비슷한 도구를 다섯 개씩 동시에 쓰면서 어디에 무엇을 남겼는지 잃어버리는 것**입니다. 그래서 필요한 것은 도구 목록이 아니라 자리 배치입니다. 다섯 자리만 정하면, 각 자리에 하나씩만 두면 됩니다.

## 다섯 자리

| 자리 | 하는 일 | 무료로 충분한 경우 |
| --- | --- | --- |
| 대화·초안 | 글쓰기, 아이디어, 코드 조각 | 하루 수십 회 이내 |
| 자료 정리 | 긴 문서·PDF 요약, 근거 찾기 | 월 몇 개 문서 |
| 회의·음성 | 녹음 전사, 회의 요약 | 주 1~2회 회의 |
| 이미지·도표 | 썸네일, 간단한 도표 | 월 몇 장 |
| 자동화 | 반복 실행, 시스템 연결 | 개인 업무 수준 |

<Callout type="note" title="한도는 계속 바뀝니다">
무료 플랜의 메시지 수, 파일 업로드 용량, 모델 접근 범위는 각 서비스가 자주 조정합니다. 이 글은 도구를 고르는 **기준**을 다루며, 구체적인 한도는 쓰는 시점에 각 서비스 화면에서 확인하는 것이 정확합니다.
</Callout>

## 대화·초안 자리

ChatGPT, Claude, Gemini 중 하나를 주력으로 정하고 나머지는 보조로 둡니다. 세 개를 번갈아 쓰면 대화 맥락이 흩어집니다.

- **긴 문서를 자주 다룬다** → 긴 입력에 강한 모델을 주력으로.
- **표·계산·스프레드시트 작업이 많다** → 표 편집과 코드 실행이 되는 쪽.
- **검색 결과를 근거로 써야 한다** → 검색 결합형을 주력으로.

주력 모델을 정할 때는 "가장 똑똑한가"보다 **내 업무 파일을 올렸을 때 형식을 덜 깨는가**로 판단하는 편이 실용적입니다.

## 자료 정리 자리

PDF, 계약서, 논문, 사내 문서를 다룰 때는 대화형 모델에 파일을 하나씩 붙이는 방식보다 **문서 묶음을 넣고 질문하는 도구**가 편합니다. 무료 범위에서도 문서 수십 개 수준은 대개 처리됩니다.

주의할 점은 하나입니다. 요약은 근거 문장을 함께 받아야 합니다. "3줄로 요약해 줘" 대신 "각 요점마다 원문 페이지와 문장을 붙여 줘"라고 요청하세요. 나중에 확인할 때 차이가 큽니다.

## 회의·음성 자리

회의 전사는 무료로도 품질이 충분한 수준이 되었습니다. 다만 두 가지를 확인해야 합니다.

1. **녹음 동의**: 참석자에게 알리고 동의를 받았는지. 지역과 상황에 따라 법적 요건이 다릅니다.
2. **보관 위치**: 전사본이 어디에 저장되고, 자동 삭제 설정이 있는지.

기밀 회의는 무료 도구에 올리지 않는 것이 원칙입니다. 대신 직접 받아쓰기 하고 요약만 맡기는 방식이 안전합니다.

## 이미지·도표 자리

블로그 썸네일, 발표 자료 표지, 간단한 도표는 무료 생성 도구로 충분합니다. 다만 **상업적 이용 조건**을 반드시 확인하세요. 무료 플랜에서 생성한 이미지의 이용 범위가 유료와 다른 경우가 많습니다. 로고·인물 사진처럼 권리 문제가 생길 수 있는 소재는 생성 도구로 만들지 않는 편이 좋습니다.

## 자동화 자리

무료 자동화는 대개 **월 실행 횟수**에 제한이 있습니다. 개인 업무는 월 수백 회면 충분한 경우가 많으니, 먼저 무료로 돌려 보고 실제 실행 횟수를 측정하세요. 측정 없이 유료로 올리면 대부분 남는 한도를 사게 됩니다.

## 조합 예시 두 가지

**1인 사업자**

- 대화·초안: 주력 모델 1개 (무료)
- 자료 정리: 문서 질의 도구 (무료)
- 회의: 전사 도구 (무료, 짧은 회의만)
- 이미지: 생성 도구 무료 크레딧
- 자동화: 스프레드시트 내장 스크립트 (무료)

**직장인 (사내 승인 필요)**

- 대화·초안: 회사가 허용한 도구만
- 자료 정리: 사내 문서는 외부 업로드 금지, 요약 기능이 있는 사내 도구 사용
- 회의: 녹음 금지 규정 확인 후 진행
- 자동화: 회사 계정 안에서 동작하는 도구로 한정

## 유료로 넘어갈 시점

다음 중 두 개 이상이면 결제를 검토할 만합니다.

- 무료 한도 때문에 **하루에 두 번 이상 기다리거나 작업을 미룬다**.
- 같은 작업을 **매일** 반복한다.
- 무료 도구의 보관 기간 때문에 자료를 옮기는 일이 생긴다.

반대로 "언젠가 쓸 것 같아서" 결제하는 것은 대부분 낭비입니다. 무료 조합으로 한 달 써 보고, 실제로 막힌 지점을 기준으로 결제하세요.
