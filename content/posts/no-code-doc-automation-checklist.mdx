"자동화"라고 하면 코드를 떠올리지만, 실제로 사무 업무에서 시간을 잡아먹는 일은 대부분 **양식 → 정리 → 파일 생성 → 전달**의 반복입니다. 이 네 단계는 코딩 없이, 또는 짧은 스크립트 한 조각으로 처리할 수 있습니다. 아래 체크리스트는 자동화를 만들기 전에 확인해야 할 것들입니다.

## 시작 전 체크리스트

- [ ] 이 일이 **주 2회 이상** 반복되는가
- [ ] 규칙이 **매번 같다**고 말할 수 있는가 (예외가 절반이면 자동화 부적합)
- [ ] 입력이 **정해진 양식**으로 들어오는가
- [ ] 출력물의 **형식이 정해져** 있는가 (파일명, 항목 순서)
- [ ] 틀렸을 때 **되돌릴 수 있는가**
- [ ] 자동 실행에 쓸 **계정**이 개인 계정이 아닌가
- [ ] 처리할 **개인정보**가 있는가, 있다면 외부 도구에 보내도 되는가
- [ ] 실패했을 때 **알림 받을 곳**이 정해져 있는가
- [ ] 원본 데이터가 바뀌면 **어디가 깨지는지** 알고 있는가
- [ ] 자동화를 **멈추는 방법**을 문서로 남겼는가

마지막 항목을 빼먹는 경우가 많습니다. 담당자가 바뀌거나 오류가 반복될 때 끄지 못하면, 잘못된 데이터가 계속 쌓입니다.

## 실제 흐름: 신청서 → 정리 → PDF → 안내 메일

가장 흔하고 효과가 큰 조합입니다.

1. **구글 폼**으로 신청을 받는다 (입력 형식이 자동으로 정해짐).
2. 응답이 **구글 시트**에 쌓인다.
3. 시트에서 필요한 항목만 골라 한 줄씩 정리한다.
4. 확정된 행에만 **PDF 생성 + 안내 메일 발송**을 실행한다.
5. 실패한 행은 시트의 상태 열에 `오류`로 남긴다.

여기서 핵심은 4번입니다. **자동 발송은 "확정" 표시가 있는 행에만** 실행하도록 조건을 둡니다. 폼 제출 즉시 메일이 나가면, 오타가 그대로 고객에게 갑니다.

## 짧은 스크립트 예시

구글 시트에서 `확장 프로그램 → Apps Script`를 열고 아래를 붙여 넣으면, 상태 열이 `확정`인 행에만 메일을 보냅니다. 스프레드시트 ID와 시트 이름만 바꾸면 됩니다.

```javascript
function sendConfirmed() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("신청");
  const rows = sheet.getDataRange().getValues();

  // 1행은 머리글: [타임스탬프, 이름, 이메일, 내용, 상태, 발송시각]
  for (let i = 1; i < rows.length; i++) {
    const [time, name, email, body, status, sentAt] = rows[i];
    if (status !== "확정" || sentAt) continue;

    try {
      GmailApp.sendEmail(email, "[안내] 신청이 접수되었습니다", name + "님, 신청이 확정되었습니다.");
      sheet.getRange(i + 1, 6).setValue(new Date());
    } catch (error) {
      sheet.getRange(i + 1, 5).setValue("오류");
      console.error("발송 실패: " + email, error);
    }
  }
}
```

그다음 `트리거`에서 `sendConfirmed`를 5분 간격으로 실행하도록 추가합니다. 발송 시각을 기록하므로 같은 사람에게 두 번 가지 않습니다.

스크립트는 실행한 계정의 권한으로 동작합니다. 개인 계정이 아니라 업무용 계정으로 만들고, 시트 공유 범위를 최소화하세요. 신청서에 주민등록번호나 카드번호가 들어온다면 자동화보다 **수집 자체를 줄이는 것**이 먼저입니다.

## 자주 깨지는 지점

| 증상 | 원인 | 대응 |
| --- | --- | --- |
| 어느 날부터 메일이 안 옴 | 무료 발송 한도 초과 | 일일 발송 수를 나누고 로그 확인 |
| 같은 사람에게 중복 발송 | 처리 여부를 기록하지 않음 | 발송 시각·상태 열 필수 |
| 파일명이 뒤죽박죽 | 이름 규칙 미정 | `날짜_이름_종류` 형식 고정 |
| 권한 오류 | 담당자 퇴사·비밀번호 변경 | 서비스 계정 또는 공용 계정 사용 |
| 양식이 바뀌자 전부 실패 | 열 순서 의존 | 머리글 이름으로 열을 찾기 |

## 문서 자동화에서 특히 유용한 세 가지

1. **템플릿 + 데이터 분리**: 문서 본문은 템플릿 파일에 두고, 데이터만 시트에서 채웁니다. 문구 수정이 쉬워집니다.
2. **PDF 파일명 규칙**: `2026-11-15_홍길동_견적서.pdf`처럼 날짜·이름·종류를 고정하면 나중에 찾기가 쉬워집니다.
3. **실행 로그 시트**: 실행 시각, 대상, 결과를 한 줄씩 남깁니다. 문제가 생겼을 때 원인 추적이 10분 안에 끝납니다.

## 정리

비개발자의 자동화는 **"완전 자동"이 목표가 아니라 "확인 한 번으로 끝나는 구조"** 입니다. 입력은 양식으로 고정하고, 출력은 규칙대로 만들고, 마지막 전달은 사람이 확인합니다. 이 세 줄이 지켜지면 코드가 조금 틀려도 사고가 나지 않습니다.
