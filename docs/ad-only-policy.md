# 무료 게임·광고 수익 운영 방향

2026-10-20, Asia/Seoul. 사용자가 **현금 유료 상품을 제외하고 광고 수익만 목표로 하는 방향**을 선택했다. 이전 문서의 외형 상품 판매·현금 결제 후속 계획보다 이 결정이 우선한다.

## 제품 범위

| 항목 | 현재 결정 |
|---|---|
| 기본 게임 | 하루 5문제·해설·기록·주간 랭킹 무료 |
| 캐릭터·꾸미기 | 기본 토끼 제공, 나머지는 플레이로 획득하는 게임 코인 사용 |
| 현금 상품 | 캐릭터·스킨·묶음 판매, 코인 충전, 유료 구독·광고 제거권 제외 |
| 기타 직접 과금 | 후원·현금성 보상·유료 뽑기·유료 연습 기능 도입 계획 없음 |
| 수익원 | 광고만 목표. 실제 광고 승인·SDK·수익 정산 미연결 |
| 가입 대상 | 만 14세 미만 포함 방침 유지 |
| 월 운영 예산 | 도메인·서버·확인 절차를 포함해 3만 원 이내 |

현재 앱에 현금 결제·PG·유료 상품 거래 기능은 없었다. 이번 변경은 남아 있던 미래 결제 안내·판매 계획을 제외하고 화면과 개발 기준을 통일한다. 게임 코인 상점의 서버 검증·가격·기존 보유 기록을 삭제하거나 코인을 현금과 교환하는 기능을 만들지 않는다.

## 보호자 동의와 유료 인증의 구분

유료 판매를 없애도 만 14세 미만 아동의 개인정보 처리에 필요한 법정대리인 동의가 자동 면제되지는 않는다. 개인정보 보호법 제22조의2는 **이 법에 따른 동의를 받아야 하는 개인정보 처리**에 대해 법정대리인의 동의와 동의 여부 확인을 요구한다. 모든 개인정보 처리의 근거가 일률적으로 동의라는 의미는 아니다. [현행 조문](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029334761)

하루다섯의 현재 가입 설계는 소셜 계정 식별자와 연결된 플레이 기록을 서버에 보관하고 동의 기반으로 아동 계정을 허용하는 구조다. 현금 판매 제외만으로 이 구조나 보호자 준비 검사를 해제하지 않는다. 실제 처리 항목별 근거와 아동–보호자 연결 검증은 공개 전에 완성해야 한다.

**유료 휴대전화 본인인증 업체만 가능한 것은 아니다.** 시행령 제17조의2에는 웹 동의 뒤 문자 통지, 본인확인, 서명한 서면, 동의 내용에 대한 이메일 회신, 전화 등 여러 방법이 규정되어 있다. [확인 방법](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lspttninfSeq=182193)

따라서 이전에 조사한 유료 인증 상품은 후보이며 필수 계약으로 확정하지 않는다. 이메일이나 전화 방식을 선택해도 실제 법정대리인에게 안내하고 동의 의사를 확인하는 절차, 요청자·대상 아동 연결, 최소 증거·보관·삭제·철회 운영이 필요하다. 단순 이메일 입력·임의 링크 클릭·성인 여부만으로 관계와 동의가 검증됐다고 표시하지 않는다. 수동 처리 비용까지 포함해 예산을 비교한다.

## 광고 도입 전 결정할 사항

- 광고 제품·계정·사이트 승인, 어린이 대상 지원, 실제 처리 항목·업체·보관·국외 처리 조건을 확인한다.
- 개인화·추적을 최소화하는 광고 방식을 우선 검토한다. 비맞춤 광고라는 이름만으로 개인정보 처리가 없다고 보지 않는다.
- 광고 위치·빈도·선택형 보상 여부는 아직 정하지 않았다. 문제 풀이 도중 강제 노출하거나 광고로 공식 도전 횟수·정답 힌트·순위 점수를 판매하지 않는다.
- 보상형 광고를 선택한다면 거절·광고 없음·오류·취소·완료를 구별하고 실제 완료 근거와 서버 중복 지급 방지를 연결한다. 현재는 광고 보상·가짜 광고 대기·추정 수익을 만들지 않는다.
- 어린이 대상 표시와 비개인화 설정을 적용하더라도 법정대리인 동의를 대신했다고 처리하지 않는다. 사업자등록·게임 관련 절차도 광고 수익만이라는 이유로 면제됐다고 판단하지 않는다.

현재 광고 스크립트·광고 쿠키·추적 도구를 추가하지 않았다. 제공자 선택과 계약·정책 검증 없이 광고 설정을 켜지 않는다. 신규 가입, 실제 보호자 확인, 독립 소셜 로그인·재인증과 자기 탈퇴 관련 준비 상태는 그대로 닫혀 있다.


## 광고 정책에서 확인한 범위

2026-10-20 공식 자료 기준으로 Google은 만 13세 미만으로 알려진 이용자와 만 13세 미만 대상 콘텐츠의 맞춤 광고·리마케팅을 제한한다. COPPA 적용 시 아동 대상 표시도 요구한다. 이 미국 기준을 한국의 만 14세 미만 개인정보 처리 기준과 혼동하지 않는다. 실제 제품별 연령 처리 방식과 적용 지역은 연결할 때 다시 확인한다. [Google 게시자 정책](https://support.google.com/adsense/answer/10502938?hl=en)

비맞춤 광고도 노출 횟수 제한과 집계 등에 쿠키·식별자를 사용할 수 있다. 따라서 비맞춤 설정만으로 개인정보 처리가 없어지거나 필요한 동의가 면제된다고 보지 않는다. [비맞춤 광고 설명](https://support.google.com/adsense/answer/9007336?hl=en)

AdSense에는 개인 계정 유형이 있으며 신청자 연령은 만 18세 이상이다. H5 게임 광고는 승인된 AdSense 계정과 별도 신청·심사를 요구한다. 개인 계정 지원은 한국의 사업자등록·세무 의무 면제를 뜻하지 않는다. 현재 하루다섯에 승인된 광고 계정이나 H5 광고 계약이 연결된 것은 아니다. [계정 유형](https://support.google.com/adsense/answer/32750?hl=en), [신청 연령](https://support.google.com/adsense/answer/14230?hl=en), [H5 광고 조건](https://support.google.com/adsense/answer/1705831?hl=en)
