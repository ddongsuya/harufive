# 가입·이용 연령 정책

2026-10-20, Asia/Seoul. 사용자의 최신 지시로 **가입·이용 대상을 만 14세 이상으로 변경**했다. 같은 날 10:12 KST에 선택했던 만 14세 미만 포함 B안을 대체한다. 문의 주소와 월 예산을 다시 선택하는 결정은 아니다.

## 현재 제품 범위

- 만 14세 미만의 신규 가입·이용과 신규 보호자–아동 연결을 출시 범위에서 제외한다.
- 만 14세 이상이 모두 성인이라는 뜻은 아니다. 청소년·미성년자에게 적용되는 법령과 제공자 정책은 별도로 확인한다.
- 무료 플레이와 광고 수익만 목표로 한다. 현금 상품·유료 코인·구독·유료 광고 제거권·후원은 제외하고 플레이로 얻는 게임 코인 상점은 유지한다.
- 실제 연령 확인, 일반 신규 가입, 독립 서버의 소셜 로그인·재인증은 아직 열지 않았다. 정책 문구나 체크박스를 실제 연령 확인 결과로 취급하지 않는다.

## 서버와 기존 데이터

서버는 최소 가입 나이를 14로 선언하되 `ageVerificationReady:false`, `under14EnrollmentOpen:false`를 유지한다. `HARU_REGISTRATION_OPEN=true`만으로 연령이 확인되지 않은 공개 신규 계정을 만들 수 없게 한다. 기존 Sites 개발 시험 계정의 제한된 예외와 기존 신원은 별개이며 연령 확인 완료를 뜻하지 않는다.

신규 보호자 요청 생성·재발급·승인은 HTTP에서 막는다. 기존 요청의 조회·거부·만료 정리와 이미 연결된 가족의 권한 있는 열람·내보내기·철회·삭제 요청은 보존한다. 내부 보호자 증빙·연결 코드는 이전 보안 회귀 검증을 위해 남겨 두며 새 가입 어댑터에 연결하지 않는다.

기존 계정의 나이를 추측해 수정하거나, 정책 변경을 이유로 가족 관계·동의 증빙·계정·게임 기록을 일괄 삭제하지 않는다. 실제 기존 자료의 보존·삭제는 요청자 확인과 정한 운영 정책에 따른다. 폐쇄 본인 계정의 후속 권리 행사·복구는 미완료이고 `selfClosure:false`, `selfRecoveryReady:false`를 유지한다.

## 공개 전에 남은 확인

1. 필요한 연령 확인 방법과 최소 증거·보유기간을 정하고 서버의 가입 허가에 연결한다. 소셜 로그인 성공, 자기신고, 성인 본인확인을 서로 같은 증거로 취급하지 않는다.
2. 게임산업법의 청소년 가입 관련 규정과 예외가 실제 운영 주체·제공 방식에 적용되는지 확인한다.
3. 실제 제공자 로그인·재인증, 운영 DB·백업·예약 삭제, 기존 가족의 권리 행사와 본인 탈퇴·삭제 절차를 검증한다.
4. 실제 처리 항목에 맞는 정책, 등급·등록·호스팅 조건과 청소년 광고 정책을 확인한 뒤 공개 범위를 정한다.

유료 휴대전화 본인인증이나 신규 아동 보호자 확인 서비스 계약을 필수 출시 과제로 확정하지 않는다. 필요한 확인 방법과 비용을 먼저 정하며 도메인·서버·인증을 포함한 월 3만 원 예산을 유지한다.

## 법령과 광고 정책의 경계

개인정보 보호법의 만 14세 미만 동의 요건과 게임산업법의 청소년 가입 규정은 별개다. 게임산업법 제12조의3은 적용 대상의 실명·연령 확인과 청소년의 법정대리인 동의 등을 규정하고, 시행령 제8조의3은 적용 범위·예외를 정한다. 실제 사업자 유형·매출·제공 방식 등을 확인해야 하며 **만 14세 이상 또는 무료 게임이라는 이유만으로 보호자 동의가 모두 면제된다고 단정하지 않는다.** [게임산업법 제12조의3](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1025570837), [시행령 제8조의3](https://law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lspttninfSeq=56576)

광고 도입에도 연령·지역별 제한과 실제 데이터 처리를 확인한다. Google의 미국 COPPA 관련 만 13세 미만 기준은 한국의 만 14세 기준과 같지 않으며, 14세 이상이라고 맞춤 광고를 무조건 허용하지 않는다. 현재 광고 계정·SDK·추적 도구는 연결하지 않았다. [광고 수익화 정책](ad-only-policy.md)을 따른다.
