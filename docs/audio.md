# 하루다섯 v0.3.1 — 배경음과 효과음

v0.3.1은 이용자별 출제·시간 점수·캐릭터 수집을 갖춘 v0.3 수정본에 배경음과 효과음을 추가합니다. 이 문서는 소리 설정, 재생 동작, 브라우저 제약과 검증 범위를 설명합니다. 프로젝트 실행과 내보내기는 `README.md`를 참고하세요.

## 소리를 켜고 조절하기

첫 실행에서는 전체 소리가 꺼져 있습니다. 상단 스피커 버튼을 누르면 소리를 켜면서 설정 창을 엽니다. 이미 소리가 켜져 있으면 같은 버튼에서 설정을 확인합니다.

| 조작 | 동작 | 처음 설정 |
| --- | --- | --- |
| 전체 소리 | 배경음과 효과음을 함께 켜거나 끕니다. | 꺼짐 |
| 배경음 음량 | 0~100%로 조절합니다. 0%는 배경음만 끕니다. | 25% |
| 효과음 음량 | 0~100%로 조절합니다. 0%는 효과음만 끕니다. | 50% |
| 완주 소리 미리 듣기 | 마지막 문제까지 마쳤을 때의 효과음을 들어봅니다. | 사용자 조작 시 재생 |
| 영입 소리 미리 듣기 | 새 친구나 아이템을 얻을 때의 효과음을 들어봅니다. | 사용자 조작 시 재생 |

미리 듣기는 현재 전체 소리 설정과 효과음 음량을 따릅니다. 소리가 꺼져 있거나 효과음이 0%이면 들리지 않습니다. 미리 듣기로 점수·코인·소유 아이템이 바뀌지 않습니다.

소리 켜기를 저장했더라도 다음 방문에서 자동으로 소리를 내지는 않습니다. 첫 사용자 조작 때 재생을 시작하며, 브라우저가 재생을 허용하지 않으면 소리 설정에서 다시 시작할 수 있습니다. 전체 소리가 켜져 있다는 설정과 실제 재생 상태를 구분합니다.

## 어떤 소리를 사용하는가

외부 음원 파일을 다운로드하지 않고 Web Audio API로 음을 합성합니다. 배경음은 이 게임을 위해 구성한 **84 BPM, 8마디, 약 23초의 반복 멜로디 한 곡**입니다. 오각음계 멜로디에 부드러운 화음과 베이스를 더했으며, 화면에 따라 같은 곡의 크기와 음의 밀도를 바꿉니다.

| 화면 | 배경음 처리 |
| --- | --- |
| 홈·프로필·랭킹 | 설정한 배경음 음량으로 기본 편곡을 재생합니다. |
| 상점 | 기본 편곡을 유지합니다. |
| 문제풀이 | 평소 배경음 크기의 32%로 낮추고 일부 멜로디 음을 생략합니다. |
| 결과 | 평소 배경음 크기의 90%로 재생합니다. |

별도의 여러 곡을 제공하는 구성은 아닙니다. 같은 화면이 다시 그려져도 진행 중인 루프를 겹쳐 시작하지 않습니다. 소리를 껐다 켜거나 화면을 숨겼다 돌아오면 정리된 루프를 다시 시작할 수 있습니다. 화면 밖에서 놓친 음들을 복귀 시 한꺼번에 재생하지 않습니다.

효과음 엔진에는 선택, 중립적인 답 제출, 완주, 전부 정답인 결과, 구매, 착용 변경, 캐릭터 인사 소리가 있습니다. **문제를 푸는 중에는 선택한 답의 정답 여부로 소리를 나누지 않습니다.** 정답 개수에 따른 결과 연출은 다섯 문제를 모두 제출한 뒤에만 가능합니다.

구매와 착용 효과음은 해당 처리가 성공했을 때 사용합니다. 잔액이 부족하거나 구매하지 않고 미리보기만 열었을 때 획득을 알리는 소리를 내지 않습니다. 결과 화면을 다시 열거나 다른 창의 저장 기록을 반영하는 것만으로 완주 보상을 반복 연출하지 않습니다.

## 시간 점수와 기억 문제

답을 확정하면 제출 시각을 기록한 뒤 효과음을 요청합니다. 오디오 컨텍스트를 활성화하거나 소리 재생을 준비하는 시간을 기다렸다가 채점하지 않습니다. 소리 설정은 정답, 점수 수식, 문제 배정, 주간 정산을 바꾸지 않습니다.

기억 배열을 보여주는 고정 시간과 답 제출 시계는 기존 시간 모듈이 관리합니다. 배경음의 박자나 효과음의 재생 종료를 문제 타이머로 사용하지 않습니다. 배열 노출 시간을 소리 재생에 맞춰 늘리거나 줄이지도 않습니다.

브라우저 탭을 숨기거나 다른 앱으로 전환하면 소리를 멈추고 예약된 음원을 정리합니다. **진행 중인 문제의 제출 시계는 계속됩니다.** 돌아왔을 때 기존에 재생을 허용한 컨텍스트만 재개를 시도하며, 브라우저가 이를 막으면 사용자 조작으로 다시 시작합니다. 소리가 멈춘 것이 문제풀이 일시정지를 뜻하지는 않습니다.

## 저장과 기존 기록 호환성

소리 설정은 `haru-five-audio-v1`이라는 별도 localStorage 키에 다음 값으로 저장합니다.

```json
{
  "enabled": false,
  "musicVolume": 0.25,
  "effectsVolume": 0.5
}
```

내부 음량은 0~1이며 화면에서는 0~100%로 표시합니다. 잘못 저장된 값은 기본값으로 보완하거나 허용 범위 안으로 제한합니다. 저장된 문자열 `"true"` 같은 값으로 소리가 실수로 켜지지 않도록, 실제 불리언 `true`만 켜짐으로 해석합니다.

게임 기록 키 `haru-five-playtest-v1`과 알림 설정 키는 그대로 유지합니다. 사운드를 추가하기 위해 기존 코인, 캐릭터 소유, 문제 스냅샷, 제출 시각, 익명 `playerId`를 다시 만들지 않습니다. 설정은 이 브라우저 안에서만 보관하며 다른 기기나 기존 사이트와 로컬 HTML 파일 사이에 자동으로 동기화하지 않습니다. localStorage가 제한된 환경에서는 재방문 때 설정이 보존되지 않을 수 있습니다.

## 브라우저 재생 정책과 오류 처리

Web Audio도 브라우저의 자동 재생 제한을 받습니다. MDN은 사용자 클릭 같은 직접 조작 안에서 `AudioContext`를 생성하거나 `resume()`하도록 설명합니다. 이 구현은 설정을 읽었다는 이유만으로 컨텍스트를 만들지 않고, 사용자 동작의 처리 안에서 재개를 요청합니다. 재생 가능한 `running` 상태를 확인한 뒤 실제 재생 중으로 표시합니다. [MDN: Web Audio API best practices](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices), [MDN: Autoplay guide](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay)

지원되지 않는 API, 생성 실패, 재개 거절, 아직 풀리지 않은 재생 제한을 구분하며, 실패했다고 게임 기록을 지우거나 문제 진행을 멈추지 않습니다. 같은 재개 요청이 겹쳐도 컨텍스트나 배경음 루프를 중복 생성하지 않습니다. 소리를 끄거나 화면을 숨기는 중에 이전 재개 요청이 늦게 끝나도 다시 소리를 내지 않도록 처리합니다. `resume()`은 비동기 결과를 반환하므로 설정 표시와 재생 성공 여부를 같은 의미로 취급하지 않습니다. [MDN: AudioContext.resume()](https://developer.mozilla.org/en-US/docs/Web/API/AudioContext/resume)

브라우저·기기·앱 내 브라우저의 정책에 따라 실제 시작과 복귀 동작이 달라질 수 있습니다. 모든 환경에서 자동으로 소리가 나거나 잠금 화면에서 계속 재생된다고 보장하지 않습니다.

## 구현과 검증 범위

- `dist/audio.js`: 설정 정규화, 지연 컨텍스트 생성, 배경음 예약, 효과음 합성, 음량·화면 상태·정리 처리.
- `dist/app.js`: 스피커 버튼과 설정 창, 별도 설정 저장, 사용자 조작과 효과음, 화면별 편곡, 숨김·복귀 연결.
- `tests/audio.test.mjs`: 오디오 API 모의 객체로 기본값, 재생 잠금, 중복 루프 방지, 개별 음량, 숨김·복귀, 실패·해제 중 경합, 종료된 음원 정리를 확인합니다.
- `tests/ui-smoke.test.mjs`: 최소 DOM 표면에서 실제 화면 컨트롤러를 실행해 게임과 설정 흐름의 연결을 확인합니다.
- `scripts/export-standalone.mjs`: 오디오 모듈을 앱 모듈 앞에 포함해 외부 음원 다운로드 없이 단일 HTML로 내보냅니다.

테스트 실행은 `npm test`와 `npm run check`를 사용합니다. 모의 오디오 검증은 실제 스피커 출력과 브라우저 정책을 재현하는 청음 테스트가 아닙니다. **이번 환경에서는 실제 기기의 스피커·이어폰 청음, 실제 모바일 브라우저의 화면·터치·재생 검수를 수행하지 못했습니다.**

실제 기기에서는 처음 소리 켜기, 재방문 후 시작, 각각 0%로 끄기, 앱 전환 후 복귀, 문제풀이 중 낮아진 음량, 완주·구매 소리의 크기를 확인해야 합니다. 약 23초 멜로디가 장시간 플레이에서 반복감을 주는지와 효과음이 대사·문제 읽기를 방해하는지도 청음하면서 조정할 항목입니다.
