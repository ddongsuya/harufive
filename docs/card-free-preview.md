# 카드 등록 없는 운영자 시험 환경

2026-10-21. **사용자가 보호된 정적 시험본을 배포하고 비밀번호로 화면에 입장했다.** 사용자 스크린샷의 저장소 준비 안내는 DB를 전달하지 않는 정적 시험본의 예상 동작이다. 소셜 로그인·게임 저장·공개 출시는 미완료다. [최신 확인 기록](codex-verification-2026-10-21.md)을 따른다.

## 선택한 범위와 현재 상태

사용자는 카드 등록 없이 진행하는 방식을 선택했다. Cloudflare Zero Trust는 활성화하지 않으며 카드 등록·Paid 전환·유료 서비스 계약을 진행하지 않는다. 도메인·서버·인증을 포함한 월 30,000원 예산은 그대로이고, 예산 확정이 결제 승인은 아니다. 기존 [비용 검토](hosting-budget.md)의 가격·한도와 원격 실측 여부를 구분한다.

Cloudflare 화면에서 최초 Hello World Worker를 만들려던 배포는 자동 승인 검토에서 거절된 이력이 있다. 이후 구체적인 생성·보호 코드 교체 과정을 설명하고 사용자 진행 승인을 받았다. 별개의 Cloudflare 사이트 접근 제한이 유지되어 사용자가 직접 생성·배포·secret 저장을 했다. 시험 원점의 관찰도 이후 도구 정책에서 차단되어 다른 도구로 우회하지 않았다. 익명 HTTP 503→401 검사는 이 차단 전에 수행했다.

별도 Worker `harufive-preview`에 운영자 1인용 시험 화면을 준비한다. 허용한 정적 자산 15개를 하나의 서버 모듈에 포함하고, **모든 경로에서 서버의 HTTP Basic 인증을 먼저 확인한다**. 기본 정적 시험본에는 DB·제공자 키를 전달하거나 실제 사용자 계정·운영 데이터를 연결하지 않는다. 서버 코어는 모듈에 포함되지만 문제은행·정답·서버 소스를 정적 자산으로 게시하지 않는다.

## 확정된 설정 계약

| 항목 | 값 또는 조건 |
|---|---|
| 시험 사용자명 | `harufive` |
| 비밀번호 secret 이름 | `HARU_PREVIEW_PASSWORD` |
| 비밀번호 형식 | 무작위 32바이트(256비트)를 패딩 없는 정규 base64url로 인코딩한 43자 |
| 원점 설정 이름 | `HARU_AUTH_ORIGIN` — 배포할 원점과 정확히 일치하도록 고정 |
| 시험 원점 | `https://harufive-preview.limjm900202.workers.dev` — 정적 시험본 배포·사용자 비밀번호 입장 확인 |

실제 비밀번호는 사용자가 해당 Worker의 Cloudflare secret에 직접 입력했다. 에이전트가 값을 받거나 읽지 않았다. 비밀번호를 채팅·GitHub·소스·로그·스크린샷·URL에 남기거나 배포하는 브라우저 JavaScript·정적 자산에 넣지 않는다. 단일 운영자 시험 범위를 유지한다.

secret이 없거나 유효하지 않으면 화면을 제공하지 않는다. 실제 원격 환경에서도 비밀번호 없는 요청·틀린 비밀번호·우회 경로 차단을 확인해야 하며, 유출이 의심되면 secret을 교체하고 다시 검증한다.

## 정적 화면 확인과 게임 인증의 차이

**기본 미리보기는 15개 정적 자산으로 구성한 안내 화면 검수용이며 게임을 플레이할 수 없다.** DB를 전달하지 않으므로 시험 비밀번호 인증 후에도 `/api/health`, `/api/auth/status`, `/api/game/bootstrap`은 모두 503을 반환한다. 이를 정상 게임 실행이나 로그인 성공으로 표시하지 않는다.

시험 비밀번호는 개인별 게임 계정·세션·연령 확인·권리 행사 권한을 만들거나 증명하지 않는다. 일반 가입·카카오/Google/네이버 로그인·재인증·신규 보호자 연결은 계속 닫혀 있고 실제 이용자 데이터나 게임 기록도 생성하지 않는다.

가입·이용 만 14세 이상, 무료 플레이·광고 수익 목표를 유지한다. 실제 연령 확인·신규 가입·광고 연결·본인 탈퇴·폐쇄 계정 복구는 별도 준비 사항이며, 기존 가족 자료의 권리 행사 정책을 이 시험 비밀번호로 바꾸지 않는다. [인증 설정 점검](auth-connection-checklist.md)을 따른다.

## 로컬 검증과 원격 확인

`npm run build:preview`와 `npm run check:preview`는 로컬 준비·검증 명령이며 원격으로 배포하지 않는다. 비밀번호 누락·오류, 모든 경로의 접근 제한, 인증 후 허용 자산만 반환, API의 503과 비밀값 미포함을 확인한다. 로컬 빌드·테스트 성공을 원격 접근 제한이나 배포 성공으로 간주하지 않으며, 이 문서에는 검증 수치를 중복 기록하지 않는다.

DB·소셜 제공자 설정을 시험 인증 뒤에만 전달하는 별도 [기존 계정 연결용 시험본](connected-preview.md)을 추가했다. 빈 DB의 첫 가입자를 만드는 기능은 포함하지 않는다. 사용자 보고에 따른 개발자 앱 등록 상태와 콜백 경로는 [제공자 앱 설정](developer-app-setup.md)을 따른다.

사용자가 `harufive-preview-db` 생성도 완료했다고 알렸다. [새 저장소 초기화·바인딩 안내](preview-database-setup.md)를 준비했으며 원격 적용 결과는 아직 확인 전이다.
