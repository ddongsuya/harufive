## 2. 현재 구현과 호스팅

소유자 비공개 Sites v0.5.0과 후속 소스의 상태를 구분한다. 로컬에는 게임·소셜 인증·최근 본인 확인·기존 가족 권리 행사·삭제 정리와 독립 Worker 준비가 있다. 실제 연령 확인·가입·소셜 제공자·광고·운영 예약 삭제·공개 배포는 아직 연결하지 않았다.

`HARU_REGISTRATION_OPEN=false`, `ageVerificationReady:false`, `under14EnrollmentOpen:false`를 유지한다. 독립 서버의 로그인·재인증도 비활성이다. 환경 변수나 연령 확인 체크박스만으로 신규 계정을 허용하지 않는다. `guardianReady:false`, `selfRecoveryReady:false`이며 본인 탈퇴·삭제 UI도 미완료다.

Workers Free + D1 Free를 후보로 두고 현재 PC 내부 무료 검증을 유지한다. Paid 도입은 유보한다. 실제 원격 계정·DB·도메인·접근 제한·결제를 구성하지 않았다. 호스팅·로그인·사이트 공개는 각각 확인해야 하며 나이 정책 변경이 기존 플랫폼의 계약 조건이나 배포 차단을 자동 해결하지 않는다.

독립 Worker 준비 단계의 전체 349개 테스트·검사·기존 5단계 빌드와 Worker dry-run, 로컬 D1 6개 마이그레이션·실제 HTTP 검증은 완료한 과거 결과다. 이번 연령 변경의 최종 결과는 [최신 검증 기록](codex-verification-2026-10-20.md)을 따른다. 실행과 비용은 [독립 Worker](standalone-worker.md), [월 예산](hosting-budget.md)을 참고한다.

## 3. 가입과 기존 자료의 처리

1. 만 14세 이상 이용 안내와 필요한 연령 확인 방법을 정한다. 불필요한 상세 생년월일·전화번호·서류를 먼저 모으지 않는다.
2. 확인 결과를 서버 가입 허가에 연결한다. 소셜 로그인이 성공했다는 사실만으로 나이가 확인됐다고 처리하지 않는다.
3. 실제 제공자·동의 및 고지·운영 DB·세션·취소·재인증을 검증한 뒤 일반 가입 공개를 검토한다.
4. 기존 계정이나 가족 관계는 자동 연령 판정·일괄 삭제하지 않는다. 다른 가족 접근 차단과 기존 열람·내보내기·철회·삭제·만료 정리를 유지한다.
5. 본인 탈퇴 이후에도 필요한 권리를 행사할 방법, 보존 기간, 백업 복원 후 재삭제와 결과 안내를 마련한다.

신규 아동 가입 어댑터나 보호자 확인 계약은 현재 필수 출시 과제가 아니다. 이전 보호자 증빙·내부 연결 코드는 보안 회귀와 기존 자료 처리에 필요한 범위로 남기며 공개 신규 연결에 사용하지 않는다.

## 4. 공개 전 운영 확인

- 만 14세 이상 중 청소년에게 게임산업법의 가입 관련 규정·예외가 적용되는지 실제 사업자 유형·매출·제공 방식으로 확인한다. 모든 보호자 동의가 면제되거나 유료 휴대전화 본인인증이 필수라고 단정하지 않는다.
- 실제 수집 항목·목적·업체·처리 국가·보유기간·공개 랭킹 범위와 개인정보 정책을 대조한다. 닉네임·임의 ID만 쓴다고 개인정보가 아니라고 단정하지 않는다.
- 문의 수신·응대, 등급분류·등록, 호스팅 접근 제한·백업·복구·예약 삭제를 확인한다.
- 기존 기록 이전은 계정의 권한을 확인한 경우만 검토한다. 브라우저 프로토타입의 점수·코인을 서버 경쟁 기록으로 가져오지 않는다.
- 광고는 제품·계정·심사·청소년 정책·개인정보 처리를 확인한 뒤 연결한다. 가짜 시청 완료·수익을 표시하거나 공식 도전 횟수·순위 이점을 광고 보상으로 제공하지 않는다.

## 6. 최초 인수인계 당시 기록 — 현재 상태표 아님

아래 표는 B안을 선택했던 최초 인수인계의 검증·배포 이력을 그대로 보존한다. 표의 어린이 가입 방향과 당시 미구현 항목은 현재 출시 계획이 아니다. 후속 구현·원격 소스 업로드·현재 검증은 인수인계와 최신 검증 기록을 우선한다.

| 구분 | 2026-10-20 확인 상태 |
|---|---|
| 운영 중인 주소 | 기존 Sites 주소의 **소유자 비공개 v0.5.0** |
| 준비한 코드 | v0.5.1 소셜 인증·계정 연결 코드와 이번 연락처·어린이 가입 준비 안내 수정 |
| 이번 화면 수정 | 로그인 전·연결 오류 화면의 하단, 내 정보, 출시 안내에 문의 메일 링크 반영 |

사용자는 배포 권한을 이미 승인했지만 자동 검토의 거부가 해제된 것은 아니다. 같은 승인을 다시 요구하거나 보호 경로를 우회해 배포하지 않는다. 이번 변경은 준비한 소스에 반영했으며 실제 사이트가 업데이트되었다고 표시하지 않는다.

이전에 v0.5.1 기반 코드에서 통과한 전체 테스트 156개와 이번의 화면 관련 20개 재검사를 구별한다. 실제 휴대폰의 화면 배치·터치·소리와 제공자 로그인은 별도 검증이 필요하다. 자세한 실행 이력은 [검증 기록](release-verification-v051.md)을 따른다.
