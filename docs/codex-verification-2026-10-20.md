## 변경

1. Node 요구 버전을 22.16.0 이상인 22.x 또는 24 이상으로 package/lockfile/README에 일치시키고 설치·빌드·로컬 실행 전에 검사한다. Node 24 선택용 `.nvmrc`를 추가했다. 의존성 패키지 버전은 그대로다.
2. 독립용 HTTP 어댑터를 추가했다. 플랫폼 인증 헤더와 Sites 예약 경로를 사용하지 않고 자체 세션만 검증한다. 가입 설정을 잘못 켜도 이 어댑터는 신규 가입을 닫는다. 기존 Sites API와 빌드 경로를 보존했다.
3. 로그인 상태에 플랫폼 기능 여부를 포함하고 독립/미확인 환경에서는 ChatGPT 로그인 버튼을 숨긴다. 기존 카카오·Google·네이버 준비 상태와 도트 화면은 유지했다.
4. 실제 SQLite 기반 D1 시험 어댑터를 로컬 DB와 테스트가 공유한다. 영속 DB의 마이그레이션 해시·중복 적용·실패 롤백을 추가했다. 데이터는 `.local/`에 보관하며 Git에서 제외한다.
5. 로컬 127.0.0.1 미리보기는 공개 게임 자산만 제공하며 비밀값·문제은행·DB 파일 경로는 제공하지 않는다. 사용자·쿠키·실제 로그인 성공을 자동 생성하지 않는다.
6. 보호자 동의·철회·삭제·예약 작업의 다음 구현 계약과 경쟁 조건 검증 목록을 문서화했다. 해당 기능의 서버·외부 확인·예약 실행을 완료한 것은 아니다.

Windows에서 열린 SQLite 파일을 정리하려던 테스트 종료 순서 오류를 발견해 DB를 먼저 닫도록 수정했다. 이후 관련 테스트와 전체 테스트를 통과했다. 최초 실패를 성공으로 계산하지 않았다.

브라우저 확인은 데스크톱 화면의 로그인 전 상태에 한정된다. 휴대폰 실기기·실제 제공자 로그인·모바일 게임 화면·오디오 청음·푸시 수신은 검증하지 않았다. Node 22.16.0에서 직접 전체 명령을 실행하지 않았으며 최소 버전은 SQLite API의 도입 버전과 고정 패키지 요구 사항을 근거로 정했다. Node 내장 SQLite의 실험 기능 경고는 남아 있다.
