# 월 3만 원 운영 예산과 연결 조건

확인일: **2026-10-20, Asia/Seoul**. 사용자가 확정한 예산은 **도메인·서버·인증을 포함해 월 30,000원 이내**이며, 운영에 사용할 **사업자등록은 아직 하지 않았다**. 가격 조사는 공식 공개 자료 기준이고 실제 견적·계약·과금 내역은 아니다.

## 현재 수익화와 확인 방법

사용자는 현금 상품을 제외하고 광고 수익만 목표로 하며 가입·이용은 **만 14세 이상**으로 변경했다. 신규 아동·보호자 연결은 출시 범위에서 제외한다. 아래 유료 확인 요금은 이전 보호자 검토의 참고 자료이며 필수 지출이 아니다. 현재 필요한 연령 확인 방법·최소 증거와 청소년 규정의 적용 여부를 정한 뒤 비용을 비교한다. [연령 정책](age-eligibility.md), [광고 전용 결정](ad-only-policy.md)을 따른다.

## 현재 권장 순서

1. 현재 PC에서 독립 Worker와 D1을 무료로 검증한다. 실제 Cloudflare 계정·DB·도메인·결제는 연결하지 않는다.
2. 외부 시험 환경이 필요해지면 Workers Free + D1 Free의 접근 제한과 실제 성능을 확인한 뒤 별도로 연결한다. 아직 호스팅을 최종 선택하거나 원격 시험 환경을 만든 것은 아니다.
3. 만 14세 이상 가입에 필요한 연령 확인 방법과 사업자등록 전 운영자의 실제 계약 조건을 비교한다. 과거 보호자 관계 확인 계약을 필수 선행 작업으로 두지 않는다.
4. Paid 전환과 도메인 구입은 실제 비용·첫 결제액·과금 제한을 확인한 후 결정한다. 소스 준비나 월 예산 확정은 유료 계약 승인이 아니다.

## 호스팅 비용

| 항목 | 공식 표시 가격·한도 | 이번 결정 |
|---|---|---|
| Workers Free | $0, 하루 100,000 Worker 요청, HTTP CPU 10ms | 무료 검증 후보. 초과하면 요청 중단 |
| D1 Free | 하루 읽기 500만 행·쓰기 10만 행, 계정 저장 5GB·DB 하나 500MB, 호출당 50쿼리 | 한도와 실제 게임·정리 쿼리를 측정해야 함 |
| Workers Paid | 계정 최소 $5/월, 요청 1천만 회·CPU 3천만 ms 포함 | 전환 유보. 포함량 초과료 별도 |
| D1 Paid | 읽기 월 250억 행·쓰기 5천만 행·저장 5GB 포함 | 초과 읽기·쓰기·저장 과금 별도 |

자료: [Workers 요금](https://developers.cloudflare.com/workers/platform/pricing/), [Workers 한도](https://developers.cloudflare.com/workers/platform/limits/), [D1 요금](https://developers.cloudflare.com/d1/platform/pricing/), [D1 한도](https://developers.cloudflare.com/d1/platform/limits/).

현재 준비 구성은 공개 경로·원점·메서드를 검사하기 위해 **모든 요청을 Worker에 먼저 보낸다**(`run_worker_first:true`). 따라서 HTML·JS·이미지도 Worker 요청 수에 포함한다. 일반적인 Static Assets 직접 응답이 무료라는 설명을 이 구성 전체의 요청 무료로 해석하지 않는다. [자산 과금](https://developers.cloudflare.com/workers/static-assets/billing-and-limitations/)

CPU 10ms 제한은 한 요청의 실행량만 제한한다. 유료 플랜의 전체 호출·D1 누적 비용을 월 3만 원에 맞춰 차단하지는 않는다. 예산 알림도 사용을 멈추지 않는다. 실제 계정에서 사용할 수 있는 과금 상한은 확인하지 않았다. 공식 2026-10-02 글의 hard spending caps 개발 계획을 현재 제공되는 보장으로 취급하지 않는다. [예산 알림](https://developers.cloudflare.com/billing/manage/budget-alerts/), [과금 상한 개발 상태](https://blog.cloudflare.com/enterprise-for-all-update/)

로컬 실행 시간과 통과 여부는 원격 Free CPU·요청·D1 한도 충족을 증명하지 않는다. 무료 초과 시 서비스가 중단될 수 있으므로 실제 부하·게임 흐름·주간 정산·자료 내보내기를 측정해야 한다. Paid를 자동 활성화하는 설정은 넣지 않았다.

## 이전 보호자 검토의 본인확인 후보 — 필수 계약 아님

| 후보 | 공개 가격 | 사업자등록 전 계약 | 남은 확인 |
|---|---|---|---|
| 포트원 경유 KG이니시스 통합인증 | 성공 건당 **40원, VAT 별도**. 단독 사용 가입비·연관리비 면제 안내 | 표준 신청은 사업자등록증 업로드. 예외 가능 여부 미확인 | 월 최소청구, 제공자별 지원, 아동–보호자 관계 증빙 |
| NICE아이디 | 공개 견적 미정 | 표준 필수서류에 사업자등록증 포함 | 초기·월·건당 요금과 관계 확인 제공 범위 |
| KCB 오케이네임 | 공개 견적 미정 | 기업고객 도입 상담. 미등록 개인 조건 미확인 | 계약 조건·요금·관계 증빙 |

자료: [포트원 통합인증 가격](https://faq.portone.io/6a1cba84-a99b-4ee1-a5a8-fffea0092399), [신청 절차](https://help.portone.io/category/procedure/pg-application/start), [NICE 이용 절차](https://niceid.co.kr/common/serv_qstn.nc), [KCB 서비스](https://www.ok-name.co.kr/).

포트원 자체 플랫폼의 인증 단독 사용료 없음과 실제 인증 제공자의 건당 비용은 별개다. 월 최소청구가 공개되지 않았으므로 0원으로 확정하지 않는다. [플랫폼 요금 FAQ](https://help.portone.io/content/content200031)

40원에 VAT 10%를 가정한 단순 계산은 성공 **100건 4,400원 / 300건 13,200원 / 500건 22,000원**이다. 최소청구·추가 옵션·관계 확인 비용이 없다는 조건의 변동비 예시이며 확정 견적이 아니다. 재확인 횟수 때문에 이용자 수와 인증 건수가 같지 않을 수 있다.

이 상품들은 본인확인 수단이다. 성인이라는 결과만으로 특정 아동의 법정대리인 관계와 하루다섯의 동의를 증명했다고 처리할 수 없다. NICE 아이핀 자체 서비스의 관계 확인 고지도 하루다섯이 해당 관계 증빙을 전달받는 계약의 근거로 사용하지 않는다. 당시 조사한 실제 제공자·동의 대상 아동 연결 계약은 미완료이며 현재 신규 아동 가입은 출시 범위에서 제외했다. 이 가격이 현재 연령 확인 요건을 충족하는 견적이라는 뜻도 아니다.

포트원은 계약 전 테스트모드 개발을 안내한다. 향후 공식 시험 설정으로 연결할 수 있지만, 이번에는 SDK·키·테스트 인증을 연결하지 않았다. 테스트 성공을 실계약·실제 보호자 확인 완료로 표시하지 않는다. [계약 전 시험 안내](https://faq.portone.io/6a1cba84-a99b-4ee1-a5a8-fffea0092399)

## 도메인과 첫 결제액

가비아의 공식 정가 공지에서 .com은 2026-10-31까지 연 24,000원, 11월 1일부터 연 25,000원(VAT 별도)이다. 10%를 더하면 각각 26,400원·27,500원이다. 실제 도메인 이름·등록 가능성·프리미엄 가격·할인은 확인하지 않았다. [가비아 가격 공지](https://www.gabia.com/gabia_notice/view.php?seq_no=45623)

연 27,500원은 월 환산 약 2,292원이지만 실제로는 연간 비용을 한 번에 낸다. **월 환산 예산과 결제하는 달의 현금 지출을 구분한다.** 예를 들어 계산용 환율 1달러=1,500원을 가정하면 도메인 27,500원과 Paid 기본 $5만으로 35,000원이다. Cloudflare 세금·환전 수수료와 인증 비용은 별도다. 이 환율은 실제 결제 환율이 아니다.

다음은 이후 계약을 비교하기 위한 **월 예산 배분 예시**다. 현재 청구액·견적·사용 허가·강제 상한이 아니다.

| 항목 | 계획액 |
|---|---:|
| 서버 기본료·환율·세금 여유 | 9,000원 |
| 도메인 연간비용 적립 | 2,500원 |
| 본인확인 성공 100건, VAT 10% 가정 | 4,400원 |
| 초과 사용·필요한 확인 절차·메일·백업 등에 남겨 둔 미배정액 | 14,100원 |
| 합계 | **30,000원** |

현재 계약 전 로컬 검증에서는 위 지출을 발생시키지 않는다. 가입비·연간 결제·별도 심사 등 일회성 비용도 실제 신청 전에 확인한다. 이 예비비로 필요한 연령 확인·등급·법률 검토 등 모든 출시 비용을 충당할 수 있다고 확정하지 않는다. 신규 아동의 보호자 확인 예산을 필수 지출로 배정하지 않는다.

## 다음에 확인할 구체적인 조건

- 미등록 개인 운영자, 만 14세 이상 무료 게임에 대한 필요한 연령 확인·인증·호스팅 계약 조건.
- 실제 필요한 연령 확인·서비스 동의의 증거, 비용, 최소청구, 해지와 제공자 보존 범위. 기존 가족 자료의 권리 행사는 보존.
- Free의 CPU 10ms·D1 호출당 50쿼리와 일일 한도 내 실제 동작.
- 외부 시험 환경의 접근 제한, 처리 위치, 운영 보관·예약 삭제·백업 복원 후 재삭제.
- 도메인 후보와 갱신 정가, 실제 첫 결제액·과금 제한.

외부 문의·신청·결제·도메인 구입·배포는 하지 않았다. 가입·이용은 만 14세 이상으로 변경하고 문의 이메일은 유지하며, `guardianReady:false`, `selfRecoveryReady:false` 및 일반 가입·로그인·재인증 비활성을 해제하지 않는다.
