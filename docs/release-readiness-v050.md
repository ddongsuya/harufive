## 3. 한국 공개 경로: 무료 운영과 시험용 운영의 선택

### 3.1 게임물 해당 여부와 등급분류

게임산업진흥법 제21조는 이용에 제공하려는 게임물의 사전 등급분류를 원칙으로 정하고, 정해진 교육·학습 목적, 시험용 게임물, 비영리 게임물 등에 예외를 둔다. 시행령 제11조의3은 비영리성 및 개인·동호회 등의 단순 공개 요건을 구체화하며 해당 여부를 미리 위원회에 확인할 수 있도록 한다. **웹브라우저에서 실행되거나 무료라는 이유만으로 예외라고 판단하지 않는다.** [S1][s1] [S2][s2]

하루다섯은 문제 풀이에 점수·주간 경쟁·등급·캐릭터 수집이 연결되어 있다. 게임물로 검토하는 것이 타당해 보이지만 이는 제품 구성에 대한 판단이며, 법적 분류 결과는 아니다. 수익화 계획이 명확하므로 서비스 명칭을 교육용·무료 체험으로 바꾸는 것만으로 비영리 예외를 적용하지 않는다.

| 가능한 경로 | 하루다섯에 미치는 영향 | 결정 기준 |
|---|---|---|
| 정식 등급분류 후 무료로 공개 | 지속 운영과 수집 기록 유지 계획을 세우기 쉬움. 이후 내용 변경·수익화 시 필요한 절차는 별도 확인 | 캐릭터·코인 기록을 이어가며 공개 운영하려는 경우 우선 검토 |
| 확인받은 시험용 게임물로 운영 | 기간·인원·무료 제공·시험용 표시·정식 전환 시 기록 처리 조건을 적용 | 정해진 기간에 시험하고 종료·초기화 계획을 고지할 수 있는 경우 검토 |

시험용 게임물은 시행령 제11조의4에 따른 확인신청 절차가 있다. 공식 별표 1의 PC·온라인·모바일 기준에는 60일 이내, 2만 명 이내, 무상 이용, 시험 중 얻은 점수·아이템 등을 정식 등급분류 유통 때 사용하지 못하도록 하는 조건이 있다. 따라서 **“베타 수집품은 정식 서비스에 모두 승계”라는 약속을 먼저 하지 않는다.** 실제 신청 시 최신 적용 기준과 연장·전환 조건을 접수기관에 재확인한다. [S3][s3] [S4][s4]

확인할 질문은 게임물 해당 여부, PC·모바일 브라우저 제공 시 신청 플랫폼과 접수기관, 예외 적용 여부, 시험용 경로의 기록 처리 조건이다. 8절에 사실관계를 담은 문의 초안을 준비했다.

### 3.2 운영 사업자와 등록은 별도의 문제

게임물 등급분류, 세무상의 사업자등록, 게임제작업·게임배급업 등록은 각각 확인한다. 현금 상품 판매를 제외한 현재 결정만으로 이 확인이 면제된다고 판단하지 않는다.

- 게임산업법 제25조에는 게임제작업·게임배급업 등록과 일부 예외가 있다. 직접 제작한 웹게임을 직접 운영하는 사업 형태에 어떤 등록이 적용되는지 관할 지자체에 확인한다. [S5][s5]
- 국세청은 사업 개시 전 또는 개시일부터 20일 이내 사업자등록 신청을 안내한다. 사업 개시 시점·업종·명의는 실제 운영 형태에 맞춰 정하며, 수익이 커진 뒤에만 등록하면 된다고 가정하지 않는다. [S6][s6]
- 현금 상품 판매·PG·판매 환불 운영은 현재 제품 범위에서 제외한다. 광고 수익을 목표로 하는 실제 운영 주체의 등록·계약·정산 관련 확인은 유지한다.

v0.5.0 스키마·인증 응답·서버 로그와 대조해 실제로 저장하는 항목만 운영 문서에 남긴다. 필요하지 않은 정보를 동의서에 추가해 수집 근거를 만드는 방식은 사용하지 않는다.

### 5.2 개인정보처리방침 작성 전 채워야 하는 실제 값

개인정보보호법 제30조는 처리 목적·보유기간·파기·위탁·권리 행사 방법·담당 연락처 등을 포함한 처리방침을 요구한다. 개인정보보호위원회의 2026년 4월 작성지침을 기준으로 실제 운영 정보를 정리한다. 아래는 **작성 입력 목록**이며 이용자에게 게시할 처리방침 초안이 아니다. [S8][s8] [S9][s9]

| 실제로 확인할 값 | 확정 전 해서는 안 되는 표현 |
|---|---|
| 처리 주체의 이름·상호, 개인정보 문의 담당·연락처 | 존재하지 않는 담당 부서·이메일 기재 |
| 인증·게임·로그별 실제 수집 항목과 수집 시점 | “어떠한 개인정보도 수집하지 않습니다”라는 포괄적 단정 |
| 항목별 처리 목적과 적법한 처리 근거 | 모든 처리를 하나의 필수 동의로 묶음 |
| 운영 중 보유기간, 탈퇴·삭제 요청 시 삭제 시점, 백업 반영 기간 | 서버·백업 동작 확인 없이 “즉시 완전 삭제” 약속 |
| 위탁 업체와 업무, 실제 보관·이전 국가·시점·방식·기간 | 업체가 글로벌 서비스라는 이유로 보관 국가를 추정 |
| 열람·정정·삭제·동의 철회 요청 방법과 처리 담당 | 동작하지 않는 계정 삭제 버튼 또는 응대되지 않는 요청 폼 |
| 공개 랭킹 범위와 탈퇴 후 표시 처리 | 계정 삭제 뒤에도 식별 가능한 공개 프로필을 무기한 유지 |

해외 인증·DB·분석·푸시 서비스를 쓰면 국외 이전 여부와 근거도 확인한다. 개인정보보호법 제28조의8은 별도 동의 외에 일정 계약 이행을 위한 위탁·보관 등의 경로도 두므로, 무조건 별도 동의가 필요하거나 무조건 처리방침만 있으면 된다고 판단하지 않는다. 실제 흐름에 맞춰 결정한다. [S10][s10]

### 5.3 아동·청소년 회원의 범위

최신 지시에 따라 만 14세 미만 신규 가입·이용은 제외하며 이전 B안의 신규 보호자 연결은 출시 과제가 아니다. 기존 가족 자료의 권한 있는 열람·철회·삭제는 유지한다. 실제 연령 확인·일반 가입은 아직 닫혀 있다. [연령 정책](age-eligibility.md)을 따른다.

게임산업법의 청소년 가입 규정은 이와 별도다. 제12조의3의 실명·연령·본인확인 및 법정대리인 동의 규정과 시행령 제8조의3의 중소기업·게임물 관련 제외가 있으므로, 실제 운영 주체·업종·서비스가 정해지면 적용 여부를 확인한다. **“14세 이상” 표기만으로 모든 게임 회원 규정이 해결됐다고 고지하지 않는다.** [S12][s12] [S13][s13]

## 6. 단계별 수익화 결정

### 단계 A: 첫 공개의 재미와 신뢰를 확인

매일 5문제, 해설, 주간 랭킹, 분야별 성장 기록을 무료로 제공한다. 무료로 얻는 코인은 외형 수집에 사용하고 양도·환전하지 못하게 한다. 연습 모드는 공식 점수에 영향을 주지 않도록 구성한다.

실제 광고가 없는데 일정 시간 기다리게 한 후 “광고 시청 완료”라고 표시하거나 광고 수익을 추정해 적립한 것처럼 보여주지 않는다. v0.5.0에서는 이런 시뮬레이션을 제거하고 실제 가능한 무료 플레이와 수집 기능을 검증한다. 측정할 핵심은 첫 5문제 완료율, 해설 열람, 다음 날 재방문, 주간 참여일 수, 첫 캐릭터 수집까지의 기간이다. 이 지표는 운영 판단용 제안이며 별도 추적 도구가 연결됐다는 뜻이 아니다.

### 단계 B: 승인된 보상형 광고를 선택적으로 연결

Google의 H5 Games Ads는 HTML5 게임의 전면·보상형 광고를 지원하지만 별도 신청제이고, 승인된 AdSense 계정이 필요하며 승인이 보장되지 않는다. Google Ad Manager에도 웹 보상형 광고가 있다. 광고 제품·계정·사이트 승인과 실제 광고 공급을 확인한 뒤 활성화한다. [S14][s14] [S15][s15]

초기 보상은 **추가 비랭킹 연습 기회 또는 외형 수집용 코인** 중에서 정한다. 공식 도전 횟수, 랭킹 점수 배수, 정답 힌트를 광고 시청 보상으로 제공하지 않는다. 보상량·일일 상한은 무료 수집 속도 측정 후 정하며, 광고를 보지 않는 이용자도 기본 5문제·해설·랭킹을 계속 이용할 수 있게 한다.

Google 정책은 보상 내용과 조건의 명확한 사전 안내, 자발적 선택, 건너뛰기·거절 시 정상 이용 보장 등을 요구한다. 직접 금전 보상은 허용하지 않고, 같은 이용자가 서비스 안에서 쓰는 양도 불가능한 게임 보상은 정해진 요건 아래 허용한다. 코인에 현금·상품권 교환이나 이용자 간 이전 기능을 추가할 경우 정책을 다시 검토한다. [S16][s16]

연결 시에는 광고 없음·오류·취소·완료를 구분한다. H5 Ad Placement API의 공통 종료 콜백은 광고가 표시되지 않아도 실행될 수 있으므로, 해당 제품의 보상 완료 콜백에서만 지급을 요청한다. 서버는 이용자별 지급과 중복 요청을 통제한다. 광고 전후에 게임과 소리가 올바르게 중지·복구되는지도 확인한다. [S17][s17]

광고 심사에는 사이트 접근성도 필요하다. AdSense는 실제 공개된 사이트와 크롤러 접근 등을 확인하므로 소유자 제한 주소에서 광고 승인이 완료됐다고 가정하지 않는다. 게임 공개 경로와 운영 준비를 먼저 갖추고 신청한다. [S18][s18]

초기 검토에 있던 정가 외형 판매 단계는 사용자의 현재 결정에 따라 제외한다. 캐릭터·스킨을 포함한 현금 상품, 유료 코인, 후원형 과금, PG와 판매 환불 기능을 후속 출시 단계로 계획하지 않는다. 무료로 얻는 게임 코인 상점은 계속 유지한다. 광고만 수익화 대상으로 검토하며 실제 광고 SDK는 아직 연결하지 않았다. [광고 수익화 정책](ad-only-policy.md)

## 7. PWA와 다음 날 알림

iOS·iPadOS 16.4 이후 홈 화면에 추가한 웹앱은 Web Push를 사용할 수 있으며, 권한 요청은 버튼 탭 같은 직접 사용자 동작에 연결해야 한다. Apple Developer Program 가입이 필수인 기능은 아니다. 실제 발송에는 웹앱 구독 처리와 서버의 구독 저장·푸시 발송이 필요하다. [S19][s19] [S20][s20]

하루다섯은 실제 푸시가 미구현이므로 캘린더 일정 추가를 “푸시 알림 설정 완료”라고 부르지 않는다. 후속 구현은 다음 흐름으로 구체화한다.

1. HTTPS, 앱 매니페스트, 홈 화면용 아이콘과 실제 기기 설치 흐름을 확인한다.
2. 결과·해설을 본 뒤 다음 날 알림을 제안하고 사용자가 선택했을 때만 권한을 요청한다.
3. 지원 환경을 기능으로 확인하고, iPhone에서는 필요한 홈 화면 추가 방법을 안내한다.
4. 동의한 구독과 원하는 알림 시각을 서버에 저장하고, 한국 날짜·이용자 설정에 맞춰 발송한다.
5. 해지·거절·만료 구독을 처리하며, 미지원 환경에는 캘린더 대안을 제공한다.

처음 방문하자마자 권한을 연속 요청하지 않는다. 푸시 구독정보의 처리 업체·보유기간·해지 방법도 5절의 데이터 정보에 반영한다. 게임 참여 알림의 선택을 광고성 메시지 수신 동의와 동일하게 취급하지 않는다.

- 기본 토끼 캐릭터를 제공하고, 다른 캐릭터·외형 아이템은 게임 내 코인으로 수집합니다.
- 코인은 양도·환전할 수 없고 외형 아이템 구매에만 사용합니다.
- 현금 상품·유료 코인·현금성 보상·유료 무작위 뽑기는 계획하지 않습니다. 광고 SDK는 현재 연결하지 않았습니다.
- 폭력·선정성 등 내용정보 요소는 제출할 실제 화면과 문제 자료를 기준으로 확인받고자 합니다.

4. 이후 계획
- 무료 플레이를 유지하며 광고 수익만 목표로 합니다. 현금 상품 판매는 제외하고, 청소년 대상 광고·개인정보 처리 조건을 확인한 뒤 이용자가 선택하는 보상형 광고를 검토하고 있습니다.
- 광고 보상은 추가 비랭킹 연습 또는 양도·환전 불가능한 외형 수집 보상으로 한정할 계획입니다.
- 첫 공개 후 수집 기록을 지속해서 운영하고 싶으나, 시험용 경로의 제한이 있다면 그에 맞춰 전환 방식을 정하겠습니다.

5. 확인 요청
가. 위 서비스가 게임산업진흥법상 게임물에 해당하는지, 필요한 등급분류 접수 경로는 무엇인지 궁금합니다.
나. PC·모바일 브라우저에서 같은 서비스를 제공할 때 신청 플랫폼과 등급 효력은 어떻게 처리해야 하는지 궁금합니다.
다. 플레이는 무료이며 광고 수익만 목표로 하는 경우, 교육·학습 또는 비영리 관련 등급분류 예외의 적용을 검토할 수 있는지 궁금합니다.
라. 시험용 게임물 확인 경로를 이용한다면 적용 기간·인원·무상 제공·표시 요건과 정식 전환 시 점수·코인·외형 아이템 처리 기준을 알려주시기 바랍니다.
마. 직접 제작한 웹게임을 직접 운영하는 위 형태에 필요한 게임제작업·게임배급업 관련 등록이나 확인 기관이 있다면 안내 부탁드립니다.
바. 이후 보상형 광고를 추가할 때 내용수정 신고 등 다시 확인해야 하는 절차를 알려주시기 바랍니다.

검토를 위해 추가로 필요한 설명서·화면·영상·신청 서식이 있다면 알려주시면 준비하겠습니다.
감사합니다.

## 9. 공개 전환을 판단하는 실제 순서

| 단계 | 확인할 구체적인 결과 | 아직 없을 때 계속할 작업 |
|---|---|---|
| 운영 정보 확인 | 개인 준비·문의 주소·만 14세 이상 정책에 더해 실제 운영자·등록 정보, 수신·응대 절차 확인 | 만 14세 이상 출시 설계, 서버 구현, 테스트, 게임 설명 자료 준비 |
| 정식 호스팅 결정 | 현재 이용 연령에 적합한 호스팅·도메인과 데이터 처리 조건 확정 | 후보 비교·이전 준비. 현재 v0.5.1 원격 저장·배포 차단을 해결 완료로 표시하지 않음 |
| 공개 경로 확인 | 등급분류 또는 적법한 예외·시험용 경로 확인, 필요한 등록 정리 | 소유자 제한 환경에서 검증, 신청 자료 보완 |
| 데이터 운영 확정 | 실제 수집·업체·보유기간·삭제 경로와 담당자 확보 | 개인정보처리방침 입력 자료 정리, 삭제·복구 기능 구현 |
| 기능 검증 | 인증·1일 1회·서버 채점·실제 랭킹·코인 거래·오류 복구의 검증 결과 | 실패 재현과 수정. 완료되지 않은 기능을 사용 가능한 것처럼 안내하지 않음 |
| 공개 환경 확인 | 결정한 정식 호스팅에서 외부 이용자 접근·모바일 화면·로그인·운영 고지 확인 | 가능한 비공개 환경에서 검증·수정하고 현재 배포 차단 상태는 별도 확인 |
| 무료 공개 | 위 결과를 바탕으로 공개 전환과 운영 시작을 결정 | 광고·푸시는 별도 준비 상태를 유지. 현금 상품·결제는 범위에서 제외 |

먼저 무료 핵심 흐름과 공정한 기록을 검증하고, 외부 심사와 연령 확인·청소년 관련 처리·운영 기능이 갖춰질 때 광고를 연결한다. 광고 SDK 연결 전까지 광고 수익이나 시청 보상이 발생하는 것으로 안내하지 않는다. 현금 상품·결제는 이후 출시 과제로 남기지 않는다. 문서 작성·버전 번호 변경·내부 배포를 정식 공개 완료의 근거로 사용하지 않는다.
