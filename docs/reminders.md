# 내일의 도전 알림 — v0.2

## 현재 제공하는 흐름

공식 도전의 해설 아래에서 알림을 제안합니다. 거절해도 게임·점수·코인에는 영향이 없고 당일 제안을 숨깁니다. 내 정보에서는 항상 다시 설정할 수 있습니다. 페이지가 열릴 때 브라우저 알림 권한을 요청하지 않습니다.

시간은 한국 시간 기준이며 기본값은 20:00입니다. 사용자가 설정창에서 본 시작일(내일)을 해당 설정 시도 동안 고정합니다. 자정을 넘어 파일을 받아도 안내한 시작일과 일치합니다. 같은 시도의 안내를 다시 열 때는 처음 준비한 날짜와 UID를 재사용합니다.

클라이언트가 표준 `.ics` 일정 파일을 생성합니다. 내용은 매일 반복되는 5분 일정, 시작 시각 표시 알림, 게임 접속 링크입니다. 파일 공유를 지원하는 기기에는 공유창을 열고, 그렇지 않으면 다운로드합니다. 공유를 취소하면 등록 상태를 변경하지 않습니다. 공유·다운로드 실패 시 수동 등록 안내로 진행할 수 있습니다.

파일이 캘린더로 직접 열리지 않는 기기에서는 날짜·시간·반복·알림·링크를 복사해 캘린더에 직접 일정을 만들 수 있습니다. 게임은 사용자의 캘린더를 읽거나 쓰지 않습니다.

## 상태와 동의

설정은 `haru-five-calendar-reminder-v1`에 별도 저장합니다. 게임 기록의 기존 키는 변경하지 않습니다.

| 상태 | 의미 |
|---|---|
| `none` | 아직 일정 준비를 시작하지 않음. 당일 거절 여부를 별도 보관. |
| `prepared` | 일정 파일 또는 수동 등록 내용을 준비함. 실제 캘린더 등록·기기 알림 허용은 확인되지 않음. |
| `confirmed` | 사용자가 “캘린더에 추가했어요”를 눌러 등록했다고 확인함. 자동 검증 결과는 아님. |

실패한 새 시간의 파일 생성은 이전에 확인한 설정을 바꾸지 않습니다. localStorage 저장이 실패하면 확인을 저장했다는 성공 메시지를 보여주지 않습니다. 브라우저의 설정 표시를 바꿔도 캘린더 일정은 자동 변경·삭제되지 않습니다. 등록 후 시간 변경 및 모든 반복 일정 삭제는 캘린더에서 해야 합니다.

## 지원 범위와 다음 구현

이 버전은 **캘린더 알림**이며 **웹앱 자체의 예약 푸시 발송은 구현하지 않습니다**. 실제 알림 수신은 캘린더에 저장한 일정과 캘린더·OS 알림 설정에 달려 있습니다. 모바일 파일 가져오기 경로는 기기에 따라 다릅니다. 실제 iPhone/Android의 공유·가져오기·알림 수신은 별도 기기 QA가 필요합니다.

실제 Web Push 도입에는 서비스워커/호환 푸시 구독, 사용자 동작에 따른 권한 요청, 기기별 구독 저장, 선호 시간과 시간대, 서버 스케줄러, 일자별 중복 발송 방지, 만료 구독 제거, 해지 기능이 함께 필요합니다. iPhone은 지원 버전에서 홈 화면에 추가한 웹앱의 Web Push 조건을 안내해야 합니다. Sites 소유자의 개인 자동화를 이용자 알림 스케줄러로 대신 사용하지 않습니다.
