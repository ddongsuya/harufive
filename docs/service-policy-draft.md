## 이번에 화면으로 제공하는 안내

`public/game/policy-views.js`의 `policyDialog('terms'|'privacy'|'data')`는 로그인 없이 읽는 고정 안내다. 이용 안내는 정식 약관 확정 전임을 표시하고 가입·동의를 받지 않는다. 개인정보 안내는 정적 시험 환경과 기존 계정 서비스, 브라우저 저장과 서버 저장을 구분한다. 데이터 관리 안내는 다운로드·접수·삭제 완료의 차이와 문의 경로를 설명한다. 광고 코드·전송·저장 기능은 없다.

운영 문의는 **limjm900202@gmail.com**이다. 안내를 닫아도 동의 기록이 생기지 않는다. 문의 버튼도 메일 작성창만 열며 자동 발송하지 않는다. 문의 메일 수신·응답 업무와 본인 확인 절차가 구현·시험됐다는 뜻은 아니다.

## 정식 정책으로 바꾸기 전에 필요한 내용

개인정보 보호법 제30조는 처리 목적·기간·파기·해당되는 제공/위탁·권리 행사·책임자 연락처·자동 수집 장치 등을 실제 처리에 맞춰 정하고 쉽게 공개하도록 규정한다. 현재 ‘준비 중’ 안내나 일반 문구로 이 항목을 채웠다고 볼 수 없다. [현재 제30조, 시행 2026-09-11](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1032645945), [개인정보보호위원회 2026.4 작성지침](https://pipc.go.kr/np/cop/bbs/selectBoardArticle.do?bbsId=BS217&mCode=D010030000&nttId=12018)

- 이용약관: 실제 운영자, 적용일·변경 안내, 가입과 계정 연결, 무료 게임/코인 규칙, 제한 사유·이의 제기, 중단·종료 안내, 이용자와 운영자의 권리·책임을 확정한다. 포괄적인 면책이나 일방적 기록 몰수 조항을 임의로 추가하지 않는다.
- 개인정보 처리방침: 위 표의 항목별 목적·근거·기간, 실제 업체·수탁/제공·국외 처리, 파기·안전 조치, 문의·권리 행사·이의 제기, 적용일과 변경 이력을 채운다. 정적 미리보기의 시험 비밀번호와 정식 계정 인증을 같은 항목으로 취급하지 않는다.
- 동의: 필요한 경우 필수·선택과 목적을 구분하고 실제 가입 처리와 연결한다. 처리방침 열람·닫기·소셜 로그인 성공을 서비스 동의나 연령 확인으로 간주하지 않는다.

## 권리 행사 운영 절차 초안

1. 이용자는 원하는 작업과 문제 화면을 문의한다. 처음부터 주민등록번호·신분증 사본·비밀번호·인증번호를 받지 않는다.
2. 운영자는 접수 사실과 대상 범위를 확인하고 검증 가능한 최소 본인/대리 권한 확인 방법을 안내한다. 이메일 주소 일치나 공개 표시 이름만으로 기록을 넘기거나 삭제하지 않는다.
3. 열람·정정·삭제·처리정지·동의 철회를 구분한다. 기존 온라인 기능은 현재 세션·대상·서버 권한 검사를 유지하며, 자기 탈퇴·폐쇄 계정의 후속 확인은 미완료로 둔다.
4. 삭제 접수, 실제 서비스 DB 삭제, 별도 보존 자료·로그·백업 처리를 나누어 결과와 남은 범위를 통지한다. 결과 불명 요청을 자동 재전송하지 않는다.
5. 처리 거절·지연·결과 이의가 있으면 이유와 가능한 후속 경로를 안내한다. 접수·증빙·결과 기록 자체의 접근 권한과 보관/파기 기간도 정한다.

이는 실행 완료된 업무 절차가 아니다. 운영 담당·확인 수단·적용 기한·예약 삭제·백업 복원 후 재삭제를 구현하고 시험해야 한다. 법령상 열람·정정/삭제·처리정지/동의 철회와 권리 행사 방법은 개인정보 보호법 제35~38조를 기준으로 요청 유형별 확인한다. [국가법령정보센터 현행법](https://www.law.go.kr/lsInfoP.do?ancYnChk=0&lsId=011357) 기술 경계는 [개인정보 운영 설명](privacy-operations.md)을 따른다.

## 광고를 연결하기 전에

Google은 후보일 뿐 선택·가입·승인하지 않았다. Context7을 먼저 조회한 뒤 공식 게시자 정책을 확인했다(2026-10-20).

- Google 광고를 쓰면 쿠키·IP 등 실제 수집·공유·이용을 처리방침에 밝혀야 한다. 이메일이나 계정의 비공개 식별자를 광고 요청에 붙이지 않는다. [게시자 개인정보 정책](https://support.google.com/adsense/answer/10502938?hl=en)
- 비맞춤 광고도 빈도 제한·집계 등에 쿠키/식별자를 쓸 수 있다. 비맞춤이라는 이름만으로 무수집·무동의를 약속하지 않는다. [비맞춤 광고 설명](https://support.google.com/adsense/answer/9007336?hl=en)
- H5 광고의 전체 화면 노출은 자연스러운 전환 지점에 두며 연속 플레이나 탐색을 방해하지 않아야 한다. 하루다섯은 시간 측정 중 문제 풀이에 강제 노출하지 않는 기존 방향을 유지한다. 보상형 여부·위치·빈도는 미정이며 가짜 완료나 임의 보상을 만들지 않는다. [H5 Games Ads 공식 안내](https://support.google.com/adsense/answer/9959170?hl=en-GB)
- AdSense 신청자는 만 18세 이상이어야 한다. 이는 게임의 만 14세 이상 이용 기준과 별개다. 한국 사업자·세무 의무 면제나 수익 보장을 뜻하지 않는다. [신청 연령](https://support.google.com/adsense/answer/14230?hl=en-ZZ)
- COPPA 관련 만 13세 기준을 한국의 만 14세 기준과 섞지 않는다. 실제 연령·대상 지역과 광고 상품별 청소년 보호 설정을 확인한 뒤 연결한다. [게시자 정책](https://support.google.com/adsense/answer/10502938?hl=en), [기존 광고 결정](ad-only-policy.md)

카드 없는 시험 환경을 준비한 것만으로 광고 계정·세금/수익 지급·사업자 조건·사이트 심사까지 완료한 것은 아니다. 광고 심사를 위해 접근 제한을 임의로 풀지 않는다.

## 필요한 최소 질문과 운영 결정

사용자에게 추가로 필요한 정보는 다음 두 가지다. 이미 정한 이메일·예산·14세 이상·무료/광고 목표는 다시 묻지 않는다.

1. 정식 서비스에 표시할 실제 운영자/개인정보 담당자의 이름은 무엇인가? 임의 회사명·실명·주소를 만들지 않는다.
2. 첫 공개 대상 지역은 한국으로 한정하는가, 해외 이용자도 포함하는가? 한국어 화면만으로 한국 한정이나 해외 접속 차단을 가정하지 않는다.

그 밖의 기술·운영 결정은 코드·호스팅 조건을 확인한 구체안으로 검토한다: 항목별 보관/삭제·백업 기간, 문의 담당과 실제 수신/응답·본인 확인 방법, 실제 호스팅/메일 업체·처리 국가, 광고 방식·위치·청소년 설정. 미정 항목을 임의로 30일/1년/국내 보관 등으로 채우지 않는다. 모두 확인되기 전 일반 가입과 광고를 열지 않는다.
