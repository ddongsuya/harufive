# v0.3.2 화면 오류 점검

점검일: 2026-10-19. 홈, 공식 도전, 기억 문제, 결과·해설, 연습, 랭킹, 내 정보, 상점·옷장·컬렉션과 관련 설정 창을 검토했습니다.

| 버전 확인 | 작은 화면에서 상단 버전 태그가 숨겨짐 | 화면 하단에도 v0.3.2를 표시 |

홈 연습 카드의 동일 그리드 셀 충돌은 CSS에서 직접 확인한 원인입니다. 다른 너비 관련 수정은 정적 레이아웃 조건과 콘텐츠 길이를 검토해 적용했으며 실제 브라우저에서 겹침을 측정한 결과와 구분합니다.

## 검증 범위

최종 통합 검증: `npm test` 8개 테스트 파일 통과, `npm run check` 통과, 단일 HTML 내보내기와 해당 파일의 컨트롤러 회귀 실행 통과. 화면 구조 검증은 **99개 실제 컨트롤러 출력 상태**를 확인했습니다. 모든 검사는 아래에 설명한 브라우저 없는 범위에 해당합니다.

### 기능과 화면 상태

`npm test`는 게임 규칙, 문제 생성, 저장 상태, 시간 측정, 캘린더, 오디오, 화면 컨트롤러와 화면 구조를 검사합니다. `npm run check`는 배포 모듈의 JavaScript 문법을 검사합니다.

`tests/screen-structure.test.mjs`는 실제 컨트롤러가 생성한 HTML을 대상으로 다음 사항을 확인합니다.

- 홈의 시작 전·완료 후와 긴 닉네임·큰 코인 수치가 있는 상태.
- 기억 문제의 준비, 배열 노출, 배열을 가린 답변 화면.
- 공식·무료 연습·보상 연습·새 문제 테스트의 결과와 정답·오답 해설.
- 랭킹, 기록 없는 프로필, 기록·배지가 있는 프로필, 샘플 기록과 여섯 분야 선택.
- 상점·옷장·컬렉션의 메뉴, 필터, 실제 목록의 선택과 피팅룸 제목 일치.
- 소리·코인·닉네임·분야 안내·등급 안내·정산·캘린더·구매·진행 중 경고 창.
- 태그의 열고 닫기, 중복 ID·속성, 버튼·링크 중첩, 입력 레이블, label·ARIA 참조, 페이지 주제목과 현재 메뉴.

`tests/ui-smoke.test.mjs`에는 다른 탭 초기화 후 결과 제거, 열린 구매창의 잔고 갱신, 자정 이후 이동, 월요일 정산의 중복 보상 방지, 새 날짜에 다른 탭이 시작한 문제와 시계 보존, 페이지 복귀, 소리 슬라이더의 외부 변경 동기화 회귀를 포함합니다.

### 반응형 규칙

320·360·375·390·414·430·480·481·620·621·768·820·821·1024·1100·1280px의 조건에서 주요 CSS 선언과 브레이크포인트의 적용 순서를 정적으로 검토했습니다. 연습 카드의 일반 흐름, 헤더 가변 높이, 보기와 주간 카드·프로필 숫자·결과 숫자의 열 수, 모달 버튼의 줄바꿈을 확인했습니다.

이 검토는 화면 16개를 렌더링해 측정한 검사가 아닙니다.

### 배포용 구성

단일 HTML 내보내기를 생성하고 같은 컨트롤러 회귀 검증으로 실행합니다. 배포에는 공식 Sites 소스 절차로 저장한 동일 소스와 정적 파일 묶음을 사용합니다.

## 남아 있는 실제 화면 검수

현재 관리형 환경에는 Sites 스킬이 요구하는 `control-browser` 기능이 제공되지 않습니다. 해당 스킬의 지침에 따라 지원되지 않는 브라우저나 임의의 서버를 설치하지 않았습니다.

따라서 이번 검증에는 실제 Safari·Chrome의 폰트와 줄바꿈, 요소 좌표·카드 높이, 화면 확대, 터치와 화면 회전, 스피커·이어폰 청음 검수가 포함되지 않습니다. 자동 검증 통과를 모든 화면에서 겹침이 없다는 실측 결과로 해석하면 안 됩니다. 실제 기기에서는 홈 완주 후 두 연습 버튼, 큰 주간 점수, 긴 문제 보기, 결과 세 항목, 상점 구매·착용과 설정 창을 우선 확인해야 합니다.
